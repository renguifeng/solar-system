# 太阳系 3D 动画 🌌

使用 Three.js 创建的太阳系 3D 动画模拟。

## 功能特性

- ✅ 太阳和 8 大行星（水星、金星、地球、火星、木星、土星、天王星、海王星）
- ✅ 行星按轨道运行，各有不同的公转速度
- ✅ 星空背景粒子效果
- ✅ 土星环
- ✅ OrbitControls 支持鼠标交互（旋转、缩放、平移）

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 操作说明

- 🖱️ **左键拖动** - 旋转视角
- 🖱️ **右键拖动** - 平移视角
- 🖱️ **滚轮** - 缩放

## 技术栈

- [Three.js](https://threejs.org/) - 3D 渲染库
- [Vite](https://vitejs.dev/) - 构建工具
